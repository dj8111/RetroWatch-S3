## 核心特徵與亮點
1. **極致超薄**：120.0 × 56.0 × 12.0 mm，整機重量約 75g。
2. **形態 A 混合固定**：左側雙平推卡榫無螺絲 + 右側 2 顆 M2 沉頭螺絲。
3. **背面鏡頭火山口保護環**：凸出 1.0mm 倒角保護環，內嵌雙面 AR 鍍膜光學鏡片，平放桌面鏡頭懸空抗磨損。
4. **側邊接口獨立分佈**：
   - **左側邊框**：沉板 Type-C 充電孔，底面完全平整無孔，70° 桌立充電不頂桌面。
   - **左右兩側邊框上角**：雙側重型手機吊飾孔，左右對稱出線，支援相機雙扣頸掛背帶（胸前懸掛時垂直水平自然下垂）或單側防掉手繩，完全不干涉正面操控與雙手握持手感。
5. **經典 CMF 美學**：半透明光固化樹脂 + Game & Watch 風格拉絲銘板 + 酒紅圓鍵 + 70° 琴鋼線折疊桌架。
6. **硬體高集成與極簡組裝**：2.4 吋 ST7789 IPS 彩色大螢幕、五向導航微動（個別接線免焊電阻）、OV5640 500 萬像素街拍鏡頭、9018 超薄壓電蜂鳴器直驅、TP4057-500mA Type-C Mini 充電模組、MicroSD 卡槽。
7. **RetroWatch OS (五合一系統)**：ESP-IDF v5.1+ 原生 C/C++，涵蓋**看盤時鐘**、**復古街拍**、**懷舊遊戲**、**微型行車記錄器 (循環覆蓋/通電自錄)** 與 **居家遠端監控 (HTTP串流/移動偵測)**。
8. **5 大風格濾鏡（以 GR 為主 + 富士風格）**：1. 原始 (無調色原圖還原)、2. GR 高反差黑白 (森山大道風)、3. GR 經典正片 (街拍膠卷)、4. 富士經典正片 (冷調紀實)、5. 富士經典負片 (懷舊日系復古)。
9. **智慧電源與狀態列**：頂部常態顯示功能/電量/Wi-Fi/音效/時間，開機 30 秒無操作自動熄屏省電（節電 >85%），點選任一鍵快速喚醒（帶防誤觸保護）。
10. **Pass-through 動態電源管理**：支援邊充邊錄、邊充邊拍、邊充邊監控，外部供電直接承擔負載，電池充飽即浮充不發燙。
11. **手機 Web 控制後台**：長按 PAUSE 鍵手機掃碼直連，免裝 App 即可配置五大模組參數並傳輸照片。
